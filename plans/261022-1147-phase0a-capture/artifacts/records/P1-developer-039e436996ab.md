### Design notes / deviations to review
1. **data_root.**
   - `check_ignore(work_tree, query) -> (exit_code, stderr)`; the query is the POSIX path of `<root>/raw/probe.jsonl` relative to the work tree, and cwd is the work tree.
   - `git_check_ignore` removes GIT_DIR, GIT_WORK_TREE, GIT_INDEX_FILE and GIT_COMMON_DIR from the child environment, so a git hook that runs pytest cannot redirect git to the wrong repo. If git cannot be launched, it returns exit -1, which becomes a `DataRootError`.
   - Error messages name only the variable and the paths.
2. **_spikelib.**
   - `spike_dir(kind, *, env=None, today=None)` requires the data root to exist already, so a mistyped root fails instead of being created. It then creates `spike/<kind>/<UTC-date>/`.
   - `require_env` treats placeholders as substrings: P4 needs "contains yourdomain.com".
   - `fetch` returns a result even on connection failure (status None, `error` set) and caps the body at 20 MB.
   - Added `utc_now()` and `write_json()` (an atomic replace) beyond the R1.7 list; both are used by portal_probe.
3. **portal_probe.**
   - Modes: the default runs robots for the five hosts (status, a 2 KB head file, and `can_fetch` per candidate URL) plus one GET of the SSC front page, then N rounds over 6 candidates:
     - HOSE today-only and HOSE two-day (both with `pageSize` = `--hose-page-size`, default 20);
     - HOSE RSS;
     - HNX RSS feed 3;
     - HNX POST with `pNumRecord=50`;
     - VSDC.
   - `--history-check` is a separate mode: HOSE `pageSize=1` for the second Wednesday of October in each year 2018..2026. The dates are computed from the year, not from the clock.
   - Limits: at least 5 s between the end of one request and the start of the next on the same host; `--interval` must be at least 60 s when `--rounds > 1`; `--timeout` must be at least 30 s (default 90).
   - Output goes to `<root>/spike/portal/<UTC-date>/<HHMMSSZ>-rounds|history/`: raw bodies, `requests.jsonl` (metadata), and `rounds-summary.json` or `history-summary.json`. The summary holds counts, latencies, skew, cookie NAMES, WAF markers, time precision and id overlap, but no titles.
   - The HNX POST form values other than `pNumRecord=50` are [ASSUMED] (empty), and so is the `X-Requested-With` header. If they are wrong, it shows as 0 rows in the summary.
4. **vnstock_probe.**
   - Imports are stdlib only (verified by grep; no `finsec_alpharadar` or `_spikelib` import). vnstock and pandas are loaded through `importlib` inside `probe` only.
   - Every subcommand refuses to run unless the interpreter is in `python -I` mode (exit 2); `--help` works under `-I`.
   - `hash`, `status` and `probe` never overwrite an existing output file (the file is opened with "x", or the run refuses).
   - `hash` keys entries as `repo:<rel>` and `home:<rel>`, so before and after runs compare across users. It also writes a `files_digest`.
   - Entry points:
     - The market entry `Market().equity(sym).ohlcv/trades` comes from a WebFetch of https://vnstocks.com/docs/vnstock/thi-truong-market (2026-10-26, vendor single source, treated as data). It is labelled [ASSUMED] in the code until it works, and the probe also records every public class for discovery.
     - `Reference().company().events()/news()`, `index.members("VN30")` and `equity.list()` come from the research (VERIFIED vendor docs).
   - Event symbols:
     - The defaults are HOSE FPT, VNM, HPG; HNX PVS; UPCOM ACV. These exchanges are [PRIOR]. The probe checks each against `equity.list()` and substitutes the first listed symbol of the right exchange on a mismatch, recording the substitution.
     - The delisted defaults are PSH, KPF and BCG, with secondary-press URLs in a code comment (https://vneconomy.vn/hose-chot-ngay-huy-bo-niem-yet-doi-voi-co-phieu-kpf-va-psh.htm, https://cafeland.vn/tin-tuc/hon-880-trieu-co-phieu-bcg-cua-bamboo-capital-bi-huy-niem-yet-bat-buoc-tu-ngay-157-153183.html). The press disagrees on the BCG date. All five defaults can be overridden on the command line.
   - Fixed date: `--as-of` defaults to 2026-10-23. Ex-dates must fall between as-of minus 3 years and as-of minus 10 days. Stock-like events (a ratio and no cash value) are picked first, the most recent first; `--exdates` overrides the pick.
   - Redaction follows R1.5 as written (`[A-Za-z0-9_\-]{24,}`) and is also applied to exception and warning message heads. Consequence: long tokens in CLI output are lost, such as a device id of 24 or more characters, sha256 values, and error codes like `VNSTOCK_INPUT_SYMBOL_UNKNOWN` (28 characters) inside message text. The `code` attribute is stored separately, unredacted.
   - Dry run: `probe` was run against an in-memory FAKE vendor object, with `importlib.import_module` patched, a fake home, global Python and pandas 3.0.5. Real vnstock was never imported (`find_spec('vnstock')` → None). All 10 step entries came back "ok", the error catalogue grouped correctly, and the rate limit stopped at the first `UserWarning`. Raw files went only to the scratchpad.
